# EasyProject v0.1 release audit

Audit date: 2026-08-08
Scope: local data integrity, desktop security, project/member rules, automated tests, build output, release documentation

## Outcome

No known P0 code blocker remains after remediation. The Windows x64 NSIS candidate builds successfully and passed a local repair-install, launch, and uninstall cycle with row-for-row application-data preservation. Public release is still blocked on signing and clean-machine/cross-platform smoke coverage.

## Remediated findings

| Area | Finding | Resolution |
| --- | --- | --- |
| Data exchange | Plan baselines were absent from full export/import | Upgraded JSON/CSV/XLSX to schema v5 and included PlanBaseline |
| Import safety | Destructive replacement needed rollback coverage | Added relationship validation, single-transaction replacement, and rollback regression test |
| Restore safety | Restore accepted arbitrary database paths | Restricted restore to verified `.db` files in the managed backup directory; added safety-snapshot test |
| Database upgrades | Schema changes had no explicit version marker | Added `PRAGMA user_version = 5`, future-version rejection, indexes, and relationship backfill |
| Calendar security | Remote ICS could target local/private services | Restricted scheme/credentials, resolved hosts, private ranges, redirects, and redirect count |
| WebView security | CSP was disabled and opener permission was broad | Added explicit CSP and scoped file-reveal permission |
| Sensitive logging | Trace/default logs could expose business payloads | Production defaults to `warn`; payload and SQL-value logging removed |
| Team integrity | Task assignees could be outside the project team | Assignment now requires an active member and active ProjectMember relationship |
| Member deletion | Owners/assignees could be removed while referenced | Removal is blocked until ownership, tasks, and team relationships are reassigned |
| Status integrity | Done tasks could retain incomplete progress | Service layer forces progress to 100% when status becomes Done |
| Startup cost | Gantt image capture loaded eagerly | `html2canvas` now loads only when an image export is requested |
