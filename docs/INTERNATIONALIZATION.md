# 国际化维护约定

## 当前候选

支持中文（zh-CN）、English（en-US）和Español（es-ES）。默认中文；用户显式选择后仅保存语言偏好，下次加载沿用。非法语言不切换。官网、登录页和工作区复用真实PrimeVue LanguageSelect；浮窗沿用自身加载时的偏好，不承诺跨窗口实时同步。

词条位于src/i18n/locales，应用、官网、状态管理各域须同时维护所有语言。当前主词典701个叶子词条；西语不整套继承英文来掩盖漏译。英文作为运行时容错回退，不代替完整性门禁。

## 新增及修改语言

1. 保持对象/数组结构、键集合和所有插值名一致；数据值、ID、枚举payload、用户名及自定义状态名称不得随界面语言改写。
2. 用literal interpolation转义vue-i18n保留字符，尤其邮箱中的@。不能因中文暂不触发就省略其它语言的实际消息编译。
3. src/i18n/primeLocales.js需覆盖已安装PrimeVue全部文案/aria键。月份与星期名由指定locale的Intl生成，技术文件单位保持通用。语言变化只更新config.locale，不能替换/关闭CSP nonce。
4. 日期显示显式使用选择语言；数据库/API的ISO日期、时区和排期算法不变。ISO日期编辑控件可保留明确yyyy-MM-dd格式，月名/星期/提示仍本地化。数字输入显式locale，小数显示可用逗号，但model仍Number，不把1,5写成业务字符串。
5. document.lang和页面描述随选择更新。技术诊断码、第三方节假日内容、用户资料/角色自由文本及合成截图中的中文数据不自动翻译；后端现有英文错误详情暂保留，未来可用稳定错误码改进，不能猜测翻译并吞掉关联冲突证据。
6. 默认状态的译名需同步共享服务端重复性校验/MCP说明，不能只在前端限制。西语别名扩展超出本轮原先仅前端的部署许可，当前待用户确认；历史冲突只报告，不合并/删除。

## 验证

src/__tests__/i18n/catalog.test.js检查键、插值、编译、PrimeVue覆盖、偏好及日历；ProgressEditor测试验证西语小数显示不写model。e2e/i18n.spec.js覆盖官网1280/960/375深浅、持久化、无账号请求、strict nonce，以及工作区1280/960深浅、真实日历/弹窗/取消无写入。加入语言后必须扩展注册及相应门禁，不删除失败断言。

完整门禁还包括类型、lint、全量单测、生产UI、真实HTTP、构建及适用原生验证。测试中的IPC为合成数据，不能据此声明真实库或macOS已验。Git/Wolai/交接与具体安装/静态部署证据见I18N_SPANISH_CHECKPOINT.md；未实际部署的候选不能称上线。
