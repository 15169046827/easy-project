## 本次更新

- 桌面/网页账号登录与开放注册；桌面保留“不登录，本地使用”，本地与账号工作区分离，不自动上传/合并。

## 下载选择

- Windows x64：NSIS安装程序（推荐），或MSI；需要WebView2。本版本要求非C盘可写安装/数据目录，C盘目录会被应用拒绝并进入存储设置。
- macOS Apple Silicon / Intel：分别提供DMG及App归档，均为实验性试用文件。当前未完成Mac实机、公证及安装/升级全矩阵验收，不保证每个macOS版本可运行。
- macOS请将App放入当前用户可写目录，例如用户自己的Applications目录；持久数据位于App包外同级EasyProject-storage，不要直接从只读DMG运行。
- `SHA256SUMS.txt`列出本次文件摘要；不要混用旧0.1.0草稿或历史安装包。

## 使用与升级前须知

- 先备份项目数据。升级可能涉及账号schema3/业务schema6及旧ID映射；不要用旧程序直接读取新库，也不要盲目恢复旧库覆盖新内容。
- 本地模式无需注册或联网。相同账号在多端访问同一远端工作区，但本地库不会自动同步到服务器；悬浮窗显示本地任务。
- 桌面安装包不会自动替换独立MCP程序或扩大客户端权限。已有独立stdio客户端须使用兼容schema6的程序和正确数据库路径。
- 在线服务处于试用阶段；共享登录/注册限流、细粒度存储配额和运维告警仍有待完善，重要内容请另存导出/备份。
