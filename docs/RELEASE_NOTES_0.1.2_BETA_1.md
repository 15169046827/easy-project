# EasyProject 0.1.2 Beta 1 — C盘存储政策修复

本版修复将维护者本机环境约束误作产品限制的问题：用户可以安装到C盘，并使用安装路径下的默认数据库，也可以指定C盘本地可写数据目录。保存密码及WebView缓存不再按盘符拒绝。

仍要求目录实际可写；网络/链接/路径穿越/迁移重叠与非空目标保护不变。权限不足时提示更换目录，不静默换库或以空库替代。升级不自动移动既有数据，不自动覆盖独立MCP或修改其权限。

未签名公开测试版，不是正式生产版。Windows包未签名，macOS未公证且未完成实机验收。不要关闭系统安全功能；仅从本项目Release下载并核对SHA256SUMS.txt。升级前备份数据。

Windows x64需WebView2和可写本地目录，支持C盘；macOS ARM/Intel为实验性试用，App应放用户可写目录，不从只读DMG运行。Mac/MSI干净设备、跨版本与混合DPI矩阵仍未正式验收；正式生产发布结论未通过。
