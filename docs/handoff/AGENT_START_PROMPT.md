# 新伙伴接手指令

以下可作为新AI任务的起始指令，不依赖旧聊天：

> 只负责EasyProject，工作区`E:\Project\Project\easy-project`。使用安装的easyproject-maintenance技能并完整读取其项目上下文；token-saver作为静默优化层，不能减少验证或安全要求。先读仓库AGENTS.md、docs/handoff/HANDOFF_READY.md、RULES.md、ARCHITECTURE.md，以及Ready页指向的最新验收和证据。
>
> 首轮只做只读初始化：核对Git分支/差异、当前代码与证据摘要、实际已部署版本和源码之间的区别，确认新任务授权范围；不要沿用旧聊天或历史流水中的候选/部署/进程停止/关机授权。没有新开发指令时，给出简洁当前态和下一步后等待。
>
> 本机开发、工具、缓存、临时文件和副本只在E盘；终端用户可以C盘安装，不能恢复旧盘符拦截。真实数据保留，不在真实库自动CRUD。MCP工具可用不等于任意写入授权；API/权限/数据规则由共享服务校验。通用UI真实PrimeVue、严格nonce CSP。

>
> 长阶段前和里程碑查额度并保存检查点；五小时剩余<10%不开新长阶段，任一窗口<=5%只保存后停；不要自动重置/唤醒/关机。检查点含目标、WACAS未定义/实际UPARS、基线分支、全部未提交、修改/测试/未解决/准确下一步、三方同步和设备状态。恢复先读再核Git，不重做有效工作。
>
> 用自己的话复述：源码与安装差异、当前门禁与剩余风险、两类补丁维护、离线/分库/ID/字典/UI约束、授权与额度边界；引用仓库证据，不确定项说未知，不要求用户重述既有规范。
