# 远端业务写入准入预算

2026-10-26源31d9b7c已按单独授权启用；实际副本/核验及后续变化以`docs/NEXT_PHASE_CHECKPOINT.md`为准。本地免登录桌面和独立stdio MCP**不受此远端预算限制**。

部署前以受限服务身份运行新二进制`check-storage`，读取相同预算环境和现有目录做元数据预检；不初始化数据库、不创建缺失工作区、不改变revision。成功只输出工作区数量，失败先人工处理，不强行启用新限制。该操作逐工作区扫描池，大量工作区应由外层维护时限约束；不能冒称恒定耗时。

默认单工作区512MiB（`EASYPROJECT_WORKSPACE_BUDGET_BYTES=536870912`），整个服务数据目录8GiB（`EASYPROJECT_DATA_BUDGET_BYTES=8589934592`）。维护者可设置每工作区64MiB—64GiB，总池须不小于工作区且不超过1TiB；仅正整数字节数，无0/负数/无限模式，非法配置拒绝启动。不从客户端接受预算设置，配置不是服务器地址输入或账号权限。

预算包含业务库、WAL/日志、全部本地恢复点/备份和审计等普通文件；总池还计入账号库等服务数据，不包含位于另一目录的运维日备份。计入已用量外，还预留“最大单文件的两倍+8MiB”以覆盖备份、旧快照恢复和请求增长。它不是512MiB纯业务正文承诺，不忽略副本占用。

Web任务/项目等业务写入、导入/备份/恢复，以及远端MCP变更，在审计、恢复点、revision变动及实际业务操作**之前**使用同一检查。达到预算拒绝新写入，Web返回507；测量失败/链接/异常文件等返回503。MCP以标准工具`isError=true`返回限定安全说明，不能泄露路径/SQL/其它账号占用量。列表/读取/导出不因该门禁封禁；账号登录、会话、密码找回等认证可继续，仍受账号/并发/频次等既有限制。

检查只读取元数据，不自动合并、删除、归档或修改任何用户内容。目录链接/路径越界/未知文件类型/计数溢出均拒绝；遍历最多20万项，协作时间5秒，不能冒称可中断挂起的文件系统调用。大量文件/低速存储可能触发安全测量失败，需维护者检查，不能以关闭检查解决。

这属于**逻辑写入准入预算，不是操作系统硬配额**：并发账号/外部操作/写入膨胀可短暂超出阈值。现阶段8业务并发及独立磁盘监测/备份预留共同减轻风险，仍需容量告警、合理扩容和异地备份；不能保证磁盘永不被其它进程填满，也没有全局账号事务配额承诺。每日运维副本另有空间预留保护，不自动清理。

触发时先检查受限回执/容量、协调写入，再由维护者决定调整预算或另行批准归档策略；保留原副本，不自动清理、恢复旧库、建空库或换数据源。增加预算不代表恢复了正式生产发布条件。
